# Compass Operations

Staff portal for Compass Drug Screening of West Michigan. Phase 1 covers check-in, lab tracking, results drafts, billing flags, and a daily briefing.

Demo data only. Do not enter real patient records until hosting and a BAA are in place.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
